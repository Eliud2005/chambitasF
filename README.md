# Descripción del proyecto

**ChambitasF** es una aplicación web desarrollada con **Angular 21** cuyo objetivo es facilitar la publicación, búsqueda y gestión de pequeñas oportunidades de trabajo o “chambitas”. El proyecto busca ofrecer una plataforma sencilla e intuitiva donde los usuarios puedan encontrar servicios u ofertas de trabajo de acuerdo con sus necesidades.

La aplicación cuenta con una estructura basada en componentes de Angular, permitiendo organizar y desarrollar las diferentes funcionalidades de manera modular. Además, está preparada para ejecutarse en un entorno de desarrollo local y posteriormente ser compilada para producción.

El proyecto forma parte del desarrollo de una solución web enfocada en conectar a personas que ofrecen sus servicios con aquellas que buscan realizar algún trabajo o contratar una actividad específica.
